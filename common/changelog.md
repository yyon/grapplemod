### Version 1.21.1-v13
- Updated to Minecraft 1.21.1
- Now runs on both Fabric and NeoForge
- Config is now handled by NeoForge's config system (Forge Config API Port on Fabric) instead of Cloth Config
- Grappling hook customizations are stored as an item component
- Wall Running, Double Jump and Sliding are now data driven enchantments
- The rope now detaches if the block it is attached to is removed while playing on a server
